Importar una lista

Funciona con tus listas privadas desde la sesión abierta de YouTube.

  1. Guarda el importador en Safari

    Arrastra este enlace a la barra de favoritos. Solo tendrás que hacerlo una vez.

    Importar a Videoteca

    Si no ves la barra: Visualización → Mostrar barra de favoritos.

  2. Abre la página completa de una lista

    Pulsa el marcador y espera a que termine de recoger los vídeos. Descargará un archivo JSON.

    Abrir YouTube ↗
  3. Importa el archivo descargado

Otra forma de ejecutar el importador

Puedes copiar el código y ejecutarlo en la consola de la página de la lista. Recoge metadatos y descarga un archivo; no accede a contraseñas ni cookies.

Conectar YouTube

Actualiza completas tus listas públicas u ocultas, con sus fechas y duraciones. Conserva tus notas, etiquetas y favoritos.

Se guarda solo en este Mac y se utiliza para consultar Google. No se incluye en las copias del catálogo.

Revisa todas las listas importadas. Como máximo una actualización automática por hora; puedes actualizar manualmente cuando quieras.

Cómo obtener la clave
  1. Abre Google Cloud y crea un proyecto, por ejemplo «Videoteca».
  2. En ese proyecto, activa YouTube Data API v3.
  3. En Credenciales, elige Crear credenciales → Clave de API. Limita la clave a YouTube Data API v3 y pégala arriba.

No necesitas OAuth ni dar acceso a tu cuenta. Las consultas salen del servidor de este Mac; una restricción por sitios web no sirve para esta conexión.

Acceso desde el móvil

Conecta el móvil a la misma Wi-Fi y abre esta dirección:

El Mac debe estar encendido y Videoteca abierta. La sesión dura hasta 12 horas. Usa una Wi-Fi de confianza: la conexión local utiliza HTTP.

Si cambia la IP o acabas de conectar el Mac a la red, pulsa Actualizar dirección. Los móviles tendrán que volver a entrar.
